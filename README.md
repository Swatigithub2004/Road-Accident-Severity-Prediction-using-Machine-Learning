# 🚦 Road Accident Severity Prediction using Machine Learning

## 📌 Overview
This project uses Machine Learning to predict road accident severity based on accident-related factors such as weather conditions, road surface, lighting, vehicle movement, and other road and driver characteristics.

The project explores accident data, identifies patterns, compares classification models, and examines the features that influence severity predictions.

## 🎯 Objectives
- Analyze road accident data using Exploratory Data Analysis (EDA).
- Clean missing values and preprocess the dataset.
- Train and compare multiple Machine Learning classification models.
- Evaluate model performance using appropriate classification metrics.
- Identify important features associated with accident severity.

## 📊 Dataset
The project uses a road traffic accident dataset containing **12,316 accident records**.

**Dataset Source:** [Road Traffic Severity Classification Dataset](https://github.com/avikumart/Road-Traffic-Severity-Classification-Project)

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Models
The following classification algorithms are implemented:
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## ⚙️ Project Workflow
1. Load and explore the dataset.
2. Handle missing values and clean the data.
3. Perform feature engineering and encode categorical variables.
4. Split the dataset into training and testing sets.
5. Train and compare the classification models.
6. Evaluate predictions using accuracy, precision, recall, F1-score, and confusion matrices.
7. Visualize model performance and feature importance.
8. Generate a sample accident severity prediction.

## 📈 Key Features
- Exploratory data analysis and visualizations
- Data preprocessing and feature engineering
- Comparison of three Machine Learning models
- Classification performance evaluation
- Random Forest feature-importance analysis
- Sample accident severity prediction

## 🚀 Getting Started

### Prerequisites
Install Python and Jupyter Notebook, then install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### Run the Project
1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.
3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `Road_Accident_Severity_Prediction.ipynb` and run the notebook cells.

**Note:** The notebook loads the dataset from an online URL, so an internet connection is required.
